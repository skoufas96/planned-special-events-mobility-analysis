# planned-special-events-mobility-analysis
Code supporting the analysis of multimodal travel demand and public transport crowding during planned special events in Washington, DC.

# Planned Special Events Mobility Analysis

This repository provides an example implementation of the analytical framework
used to assess the impacts of planned special events on multimodal travel demand.

The provided Python script demonstrates the event-versus-control comparison
approach for Capital Bikeshare data, including the identification of stations
around event venues, estimation of excess event-related trips, temporal
aggregation, and sensitivity analysis for different spatial radii.

A comparable analytical approach was applied to the public transport and
ride-hailing datasets used in the study.

## Data availability

Capital Bikeshare trip history data are publicly available from the Capital
Bikeshare open data portal:
https://capitalbikeshare.com/system-data

The public transport passenger journey, rail movement, and ride-hailing
datasets used in the study are subject to access restrictions and cannot be
publicly shared by the authors.

The repository is intended to demonstrate the transferable analytical
framework rather than provide a fully reproducible implementation of the
complete empirical analysis.
